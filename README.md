# 🎨 CSS Visual Showcase — Efectos Modernos con CSS Puro

Colección de efectos visuales avanzados construidos exclusivamente con CSS moderno. Cada efecto dispone de su propia página interactiva para visualizar su funcionamiento y explorar diferentes técnicas de diseño y animación.

El objetivo del proyecto es demostrar cómo crear experiencias visuales atractivas utilizando únicamente HTML y CSS, sin recurrir a frameworks ni librerías de animación.

🌐 **Ver demo en producción**

👉 https://showcase-css.vercel.app

---

# ✨ Efectos Incluidos

| Efecto                | Descripción                                                  |
| --------------------- | ------------------------------------------------------------ |
| Timing Functions      | Comparación visual de curvas de aceleración y desaceleración |
| Background Blur       | Desenfoque dinámico aplicado a elementos visuales            |
| Text Mask             | Texto relleno mediante imágenes utilizando máscaras CSS      |
| Slider sin JavaScript | Galería interactiva construida únicamente con CSS            |
| Before & After        | Comparación visual entre imágenes                            |
| Color Overlay         | Capas de color y efectos de mezcla                           |
| Animación CSS         | Transformaciones y movimientos mediante keyframes            |
| Hover Effects         | Interacciones visuales al pasar el cursor                    |

# 🧱 Arquitectura

## Estructura del Proyecto

```text
showcase-css/
├── css/
│   ├── main.css
│   └── [efecto].css
├── efectos/
│   └── [efecto].html
├── img/
│   └── ...
└── index.html
```

## Organización

| Carpeta    | Función                                         |
| ---------- | ----------------------------------------------- |
| css        | Estilos globales y específicos de cada efecto   |
| efectos    | Páginas independientes para cada demostración   |
| img        | Recursos gráficos utilizados                    |
| index.html | Página principal con acceso a todos los efectos |
